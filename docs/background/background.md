# From pilots to wider use

This history is optional reading after the [20-minute lesson](../index.md).

OGC Testbeds 13–15 explored application deployment near EO data. The 2019–2020 EO Applications Pilot tested interoperability between providers and informed the Best Practice for Earth Observation Application Package. The published best practice remains the reference for this module. [OGC Best Practice](https://docs.ogc.org/bp/20-089r1.html).

By 2026, introductory teaching should also cover ESA's EOEPCA initiative and its evolution, EOEPCA+. The initiative develops interoperable building blocks for EO platforms and federation; its Processing architecture supports OGC Application Packages expressed in CWL. This gives students a concrete path from the early packaging experiments to reusable platform services. Support and onboarding requirements still depend on the deployment. [ESA Common Architecture initiative](https://eo4society.esa.int/common-architecture/), [EOEPCA processing architecture](https://eoepca.readthedocs.io/projects/architecture/en/latest/reference-architecture/processing-BB/).

For the earlier architecture, read [previous OGC testbeds](previous-ogc-testbeds.md), [the EO Applications Pilot](applications-pilot.md) and [the published best practice](eoap-best-practice.md). Historical references to WPS, EMS and ADES describe that period; present deployments may expose different services and onboarding paths.
