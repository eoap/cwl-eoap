# The published OGC Best Practice

The [OGC Best Practice for Earth Observation Application Package, 20-089r1](https://docs.ogc.org/bp/20-089r1.html) documents how to package EO applications using a command-line interface, container software and CWL workflow descriptions. It also covers metadata, application patterns and platform responsibilities.

It is a published best-practice document, not a guarantee that an arbitrary package runs on every platform. A deployment needs compatible CWL features, accessible software and data, and appropriate runtime resources.

For this module, first learn to identify the workflow interface, tool bindings, container reference and outputs in [the example](../quick-start.md). Consult the original document when you need exact requirement wording or guidance for a production package.
